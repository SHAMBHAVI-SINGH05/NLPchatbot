# NLP Chatbot with Sarcasm Detection

This project is a simple NLP-based chatbot that uses a sarcasm detection model to identify whether a given user input is sarcastic or non-sarcastic.

The chatbot loads a sarcasm dataset, preprocesses text data, trains a machine learning model, and then allows users to interact with it through the terminal.

---

## Features

- Sarcasm detection using NLP
- Text preprocessing and cleaning
- Stopword removal using NLTK
- Machine learning-based classification
- Terminal-based chatbot interaction
- JSON dataset support

---

## Tech Stack

- Python
- NLTK
- scikit-learn
- JSON dataset
- Machine Learning / NLP

## How to Run

Install required libraries:

```bash
pip install nltk scikit-learn
```

Run the chatbot:

```bash
python chatbot_sarcasm.py
```

To exit the chatbot, type:

```bash
exit
```
